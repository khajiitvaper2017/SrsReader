# Початок роботи

1. Додайте одну або кілька мов до списків **Мови, які ви вивчаєте** та **Рідні мови**. Браузер пропонує першу рідну мову. Вона використовується для перекладу.
2. У розділі **Словники** виберіть вкладку потрібної мови та імпортуйте її словник. Доступні завантаження описано в [довідці про словники](dictionaries.md).
3. Виберіть спосіб пошуку, наприклад **Середня кнопка миші** або **Shift + наведення**. За замовчуванням нічого не вибрано.
4. Натисніть **Завершити налаштування**. Програма завантажить доступні словоформи й приклади речень для кожної мови, яку ви вивчаєте.

Відкрийте сайт, викличте словник вибраною дією та натисніть **Зберегти слово**. Щоб вивчати збережені слова, відкрийте **Повторення**.

Змінити мови можна в **Налаштування → Загальні → Мови**. Для **Мови інтерфейсу** доступні англійська, українська або **Як перша рідна мова**. Автоматичний вибір використовує першу рідну мову; якщо це не англійська чи українська, інтерфейс буде англійською. Початкові налаштування можна відкрити повторно в розділі **Налаштування → Загальні**. Вкладка **Довідка** доступна й під час налаштування.

У списку **Рідні мови** виберіть хоча б одну мову. Перша мова задає мову перекладу. Фільтр завантаження словників Вікісловника включає всі вибрані рідні мови. Словникові визначення цими мовами показуються без перекладу. Щоб змінити порядок, перетягніть вибрані мови. Для керування клавіатурою перейдіть до поля й натисніть стрілку вліво, щоб вибрати мову. Потім натисніть Alt + стрілку вліво чи вправо, щоб перемістити її. У списках і вкладках мов біля назв показано прапорці.

Спочатку виберіть розділ налаштувань, а потім вкладку мови під ним. В адресі зберігаються вибрані розділ, мова й тип словника. Після перезавантаження сторінки або переходу назад чи вперед відкриється відповідна вкладка.

У списку **Мови, які ви вивчаєте** під кожною мовою показано підтримувані функції: граматичний аналіз через UDPipe, додаткові словоформи, онлайн-словник Nechybujte та завантаження прикладів речень. Мови з більшою кількістю функцій показано першими. Мови з однаковою кількістю функцій упорядковано за абеткою мовою інтерфейсу. Підписи показують підтримку, навіть якщо функцію вимкнено або її дані ще не завантажено. Озвучення тексту залежить від голосів, установлених на вашому пристрої, і не впливає на порядок.

## Тема

Відкрийте **Налаштування → Загальні → Тема**. Виберіть **Світла**, **Темна**, **OLED (чорна)** або **Системна**, щоб використовувати тему пристрою. Темна тема має майже чорне тло, а OLED — чорне. В обох темах другорядні підписи лише трохи темніші за основний текст.

**Акцентний колір** задає колір кнопок, посилань і вибраних елементів. За замовчуванням це помаранчевий (`#D26400`). Скористайтеся палітрою або введіть шестизначний шістнадцятковий код, наприклад `#0080FF`. Тема й акцентний колір також діють у спливному словнику.

## Завантаження збірки в браузер

- **Chrome:** відкрийте `chrome://extensions`, увімкніть **Режим розробника**, натисніть **Завантажити розпаковане розширення** та виберіть `.output/chrome-mv3`.
- **Firefox:** відкрийте `about:debugging#/runtime/this-firefox`, натисніть **Завантажити тимчасовий додаток** і виберіть `.output/firefox-mv3/manifest.json`.

Firefox видаляє тимчасові додатки після закриття браузера. Зберігайте [резервні копії](data.md); для постійного встановлення потрібен підписаний пакет.

## Автоматичне перезавантаження

Використовуйте збірку для розробки, щоб розширення автоматично перезавантажувалося після змін у вихідних файлах.

1. У папці проєкту запустіть `pnpm dev` для Chrome або `pnpm dev:firefox` для Firefox.
2. Вимкніть звичайну збірку, якщо її встановлено. Не видаляйте її, щоб зберегти дані.
3. У Chrome натисніть **Завантажити розпаковане розширення** та виберіть `.output/chrome-mv3-dev`. У Firefox натисніть **Завантажити тимчасовий додаток** і виберіть `.output/firefox-mv3-dev/manifest.json`.
4. Залиште команду працювати, поки редагуєте файли.

WXT оновлює сторінки розширення та за потреби перезавантажує фоновий процес і скрипти на сайтах. Звичайна команда `pnpm build` не вмикає автоматичне перезавантаження. Щоб зупинити сервер розробки, натисніть Ctrl+C у його терміналі.

Chrome вважає збірку з папки для розробки окремим розширенням з окремими даними. Звичайне розширення зберігає свої дані. Скористайтеся [резервними копіями](data.md), щоб скопіювати збережені слова й налаштування, та імпортуйте словники у збірку для розробки.
