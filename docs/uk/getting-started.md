# Початок роботи

1. Додайте одну або кілька мов до списку **Мови, які ви вивчаєте** та перевірте **Рідну мову**. Рідна мова визначається за мовою браузера й використовується для перекладу.
2. У розділі **Словники** виберіть мову в полі **Налаштування для мови** та імпортуйте її словник. Доступні завантаження описано в [довідці про словники](dictionaries.md).
3. Виберіть спосіб пошуку, наприклад **Середня кнопка миші** або **Shift + наведення**. За замовчуванням нічого не вибрано.
4. Натисніть **Завершити налаштування**. Програма завантажить доступні словоформи й приклади речень для кожної мови, яку ви вивчаєте.

Відкрийте сайт, викличте словник вибраною дією та натисніть **Зберегти слово**. Щоб вивчати збережені слова, відкрийте **Повторення**.

Змінити мови можна в **Налаштування → Загальні → Мови**. Для **Мови інтерфейсу** доступні англійська, українська або **Як рідна мова**; для інших рідних мов використовується англійський інтерфейс. Початкові налаштування можна відкрити повторно в розділі **Налаштування → Загальні**. Вкладка **Довідка** доступна й під час налаштування.

## Тема

Відкрийте **Налаштування → Загальні → Тема**. Виберіть **Світла**, **Темна**, **OLED (чорна)** або **Системна**, щоб використовувати тему пристрою. Темна тема має майже чорне тло, а OLED — чорне. В обох темах другорядні підписи лише трохи темніші за основний текст.

**Акцентний колір** задає колір кнопок, посилань і вибраних елементів. За замовчуванням це помаранчевий (`#D26400`). Скористайтеся палітрою або введіть шестизначний шістнадцятковий код, наприклад `#0080FF`. Тема й акцентний колір також діють у спливному словнику.

## Завантаження збірки в браузер

- **Chrome:** відкрийте `chrome://extensions`, увімкніть **Режим розробника**, натисніть **Завантажити розпаковане розширення** та виберіть `.output/chrome-mv3`.
- **Firefox:** відкрийте `about:debugging#/runtime/this-firefox`, натисніть **Завантажити тимчасовий додаток** і виберіть `.output/firefox-mv3/manifest.json`.

Firefox видаляє тимчасові додатки після закриття браузера. Зберігайте [резервні копії](data.md); для постійного встановлення потрібен підписаний пакет.
