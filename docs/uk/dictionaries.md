# Словники

## Встановлення й оновлення

Відкрийте **Налаштування → Словники**:

- **Словники Вікісловника:** виберіть мову навчання й мову тлумачень, потім натисніть **Імпортувати**. **Визначення** містять повні статті, **Переклади** — коротші відповідники. Для одномовного словника виберіть однакову мову з обох боків.
- **Частотні словники:** виберіть мову й корпус, потім натисніть **Імпортувати**. Вони надають частотні ранги, тому для читання також потрібен словник із тлумаченнями.
- Натисніть **Вибрати ZIP** або перетягніть файл у поле імпорту, щоб установити словник формату Yomitan 3. Якщо файл не містить відомостей про мову, спочатку виберіть мову навчання.

Не закривайте налаштування під час завантаження й імпорту. Встановлені словники працюють без інтернету.

Кнопками **↑** і **↓** змінюйте пріоритет тлумачень: вищі словники показуються першими. Зніміть позначку, щоб вимкнути словник.

**Налаштування → Читання та вигляд → Показувати лише перший словник** увімкнено за замовчуванням. Показуються всі тлумачення з першого словника, де знайдено слово. Кнопка **Інші словники** відкриває решту статей, а **Лише перший словник** згортає їх. Вимкніть це налаштування, щоб завжди бачити всі словники.

Натисніть **Перевірити оновлення**, а потім **Оновити**, якщо є нова версія. Перевірка запускається вручну. Якщо джерела оновлень немає, імпортуйте новіший ZIP із тією самою назвою й мовами.

У **Налаштування → Читання та вигляд → Ігнорувати слова за позначками** виберіть позначки, щоб позначити відповідні слова як **ігноровані**. У спливному словнику натисніть позначку й виберіть **Ігнорувати**. Ігноровані слова типово не підсвічуються, але їхні словникові статті залишаються доступними. Задайте колір у **Кольори слів → Ігноровані** або зніміть позначку, щоб повернути звичайне підсвічування. Самі позначки залишаються видимими; наведіть курсор, щоб побачити пояснення зі словника. Вибір зберігається під час експорту налаштувань.

## Частота

Менший ранг означає частіше слово. Позначка **Част.** у спливному вікні об’єднує дані ввімкнених частотних словників; наведіть курсор або натисніть її, щоб побачити окремі ранги. Порядок словників не впливає на спільний ранг.

Нові картки вводяться від частіших слів до рідкісніших. У **Налаштування → Інтервальне повторення → Слова без частоти** виберіть **Вводити останніми** або **Призначати випадкову частоту**. Розклад уже вивчених карток не змінюється.

## Відсутні слова

У **Налаштування → Словоформи** завантажте додаткові форми, якщо вони доступні. Форми ведуть до початкових слів у словнику й використовують ті самі картки. Якщо запропоновано кілька варіантів, виберіть потрібний.

Форма може бути розпізнана, навіть якщо її початкове слово не має тлумачення. Додаткові словоформи цього не виправлять: потрібен інший словник із тлумаченнями. Чеський пошук без префікса `z-` позначається як **доконаний**; значення знайденого слова може відрізнятися від слова з префіксом.

Для відсутніх чеських форм дієслів на **-čovat**, наприклад **dosvědčoval**, пошук може використати доконаний відповідник на **-čit** (**dosvědčit**). Позначка **недоконаний** описує вихідну форму: тривалу або повторювану дію, а не завершену. Наявна словникова стаття має пріоритет.

## Nechybujte онлайн

Для вивчення чеської ввімкніть **Налаштування → Словники → Nechybujte (онлайн)**, щоб додати визначення, граматику й приклади з Nechybujte. Типово цю опцію вимкнено; ключ API не потрібен. Слова, які ви відкриваєте, надсилаються до Nechybujte; розпізнавання сторінки залишається локальним.

Імпортовані словники показуються першими. Розгорніть **Інші словники**, щоб побачити Nechybujte, якщо є локальне визначення. Отримані статті та словоформи зберігаються на цьому пристрої без обмеження строку й використовуються для локального розпізнавання сторінок, зокрема після перезапуску браузера. Повторний пошук використовує збережені дані. Кнопка **Оновити зі словника** для збереженого слова завантажує свіжу копію. Вимкніть опцію, щоб припинити онлайн-запити; збережені статті залишаться доступними. Додані до повторень статті також входять до експорту слів.
