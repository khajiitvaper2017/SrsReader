# Словники

## Встановлення й оновлення

Відкрийте **Налаштування → Словники**:

- **Словники Вікісловника:** виберіть мову навчання й мову тлумачень, потім натисніть **Імпортувати**. **Визначення** містять повні статті, **Переклади** — коротші відповідники. Для одномовного словника виберіть однакову мову з обох боків.
- **Частотні словники:** виберіть мову й корпус, потім натисніть **Імпортувати**. Вони надають частотні ранги, тому для читання також потрібен словник із тлумаченнями.
- Натисніть **Вибрати ZIP** або перетягніть файл у поле імпорту, щоб установити словник формату Yomitan 3. Якщо файл не містить відомостей про мову, спочатку виберіть мову навчання.

Не закривайте налаштування під час завантаження й імпорту. Встановлені словники працюють без інтернету.

Кнопками **↑** і **↓** змінюйте пріоритет тлумачень: вищі словники показуються першими. Зніміть позначку, щоб вимкнути словник.

Натисніть **Перевірити оновлення**, а потім **Оновити**, якщо є нова версія. Перевірка запускається вручну. Якщо джерела оновлень немає, імпортуйте новіший ZIP із тією самою назвою й мовами.

## Частота

Менший ранг означає частіше слово. Позначка **Част.** у спливному вікні об’єднує дані ввімкнених частотних словників; наведіть курсор або натисніть її, щоб побачити окремі ранги. Порядок словників не впливає на спільний ранг.

Нові картки вводяться від частіших слів до рідкісніших. У **Налаштування → Інтервальне повторення → Слова без частоти** виберіть **Вводити останніми** або **Призначати випадкову частоту**. Розклад уже вивчених карток не змінюється.

## Відсутні слова

У **Налаштування → Словоформи** завантажте додаткові форми, якщо вони доступні. Форми ведуть до початкових слів у словнику й використовують ті самі картки. Якщо запропоновано кілька варіантів, виберіть потрібний.

Форма може бути розпізнана, навіть якщо її початкове слово не має тлумачення. Додаткові словоформи цього не виправлять: потрібен інший словник із тлумаченнями. Чеський пошук без префікса `z-` позначається як **доконаний**; значення знайденого слова може відрізнятися від слова з префіксом.
